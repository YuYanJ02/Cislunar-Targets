# 数据符合性分析框架

## 内符合分析

内符合分析评价同一来源内部的连续性，不需要真实轨道。

典型方法：

- 将连续两组 TLE/OMM 传播到相同历元，计算重叠弧状态差；
- 比较同一目标历次更新的半长轴、偏心率和轨道周期跳变；
- 将单个 TLE/SGP4 轨道与由该 TLE 伪观测拟合得到的数值轨道比较。

建议在 RIC/UVW 坐标系中统计径向、沿轨和面外残差，并记录预测时间长度和元素集年龄。

## 源间符合分析

源间符合分析比较 Space-Track 与 Bill Gray：

```text
Space-Track 状态(t) - Bill Gray 状态(t)
```

两套轨道必须传播到同一时间、同一坐标系和同一时间系统。网页当前给出的半长轴、周期和历元差只用于快速发现异常，不能代替状态矢量残差分析。

源间差异较小只表明两套数据彼此接近，不能判断哪一个更接近真实轨道。

## 外符合分析

外符合分析需要独立高精度参考：

- 任务方精密星历；
- ILRS、IGS、DORIS 等精密轨道产品；
- 独立测角、测距或测速数据定轨结果；
- 经验证的 OEM/SP3 等轨道产品。

基本关系为：

```text
目录轨道状态(t) - 高精度参考状态(t)
```

只有外符合结果才能用于评价相对于参考真值的绝对轨道误差。

## 分组建议

误差统计至少按以下变量分组：

- 数据来源；
- 轨道类别；
- 偏心率区间；
- 倾角区间；
- 近地点和远地点区间；
- 元素集年龄；
- 预测时间长度；
- 活动、机动或任务状态；
- 标准 TLE 与 Bill Gray 扩展类型。

高偏心率、地月转移、L1/L2 和逃逸轨道应单独处理，不能直接套用普通 GEO 目标的经验误差。

## 推荐统计量

- RIC 三方向均值和标准差；
- 中位数和 MAD；
- 50%、68%、95%、99% 分位数；
- 三维位置差和速度差；
- 按预测时长归一化的误差增长；
- 异常跳变次数和持续时间；
- 双源可用率和历元覆盖率。

异常值应单独标记并保留原始记录，不应在没有说明的情况下直接删除。
